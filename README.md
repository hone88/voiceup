# VOICEUP

思いついた「欲しい」「困った」を、声でそのまま投稿できるWebアプリ。
広島工業大学での学内実証用プロトタイプ。

- 声で投稿（ブラウザの音声認識。iPhoneは Siri と音声入力がオンのとき動作）
- 投稿前の確認、匿名 or ニックネーム
- みんなの声（新着／共感順、カテゴリ絞り込み）、「わかる」で共感
- 自分の投稿の削除、他人の投稿の通報

Firebaseを設定するまでは「お試しモード」で動き、投稿はその端末の中だけに保存されます。

## Firebaseのつなぎ方（約10分）

1. **プロジェクトを作る**
   [Firebaseコンソール](https://console.firebase.google.com/) → 「プロジェクトを追加」→ 名前を `voiceup` などにして作成（Googleアナリティクスはオフでよい）。

2. **Webアプリを登録して設定値をコピー**
   プロジェクトのトップ → `</>`（ウェブ）アイコン → アプリ名 `voiceup` で登録。
   表示される `firebaseConfig = { ... }` の中身を、このリポジトリの `firebase-config.js` に貼る。

3. **匿名ログインをオンにする**
   左メニュー「構築 > Authentication」→「始める」→「Sign-in method」→「匿名」を有効にして保存。

4. **データベースを作る**
   「構築 > Firestore Database」→「データベースの作成」→ ロケーションは `asia-northeast1（東京）` → 本番環境モードで作成。

5. **セキュリティルールを貼る**
   Firestore の「ルール」タブを開き、このリポジトリの `firestore.rules` の中身をまるごと貼って「公開」。

6. **公開URLを許可する**
   「Authentication > 設定 > 承認済みドメイン」に `hone88.github.io` を追加。

これで、公開ページを開いた全員の投稿と共感がリアルタイムで共有されます。

## 通報の確認

通報は Firestore の `reports` コレクションに入ります（アプリ上には表示されません）。
Firebaseコンソールの Firestore 画面から確認し、問題のある投稿は `posts` から削除してください。
